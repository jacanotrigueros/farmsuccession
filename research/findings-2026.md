# What the 2026 research found

Territory by territory: what each pass published, what it looked for and did not find, what it considered and left out, and what it has still to settle. The data files hold the evidence; this holds the conclusions, which are most of the work and invisible in the result.

Generated by `npm run report -- 2026` from the edition files and the research briefs, and `npm run check` fails when the committed file is not what the data produces. The prose is English; what a researcher or a page wrote is quoted in its own language, because translating a conclusion would be inventing one.
