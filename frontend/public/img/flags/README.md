# Flags

Eleven files, drawn beside a country's name at 24×18 pixels.

They are files rather than emoji because a flag emoji is a pair of regional indicator letters and
Windows ships no glyph for the pair: every Windows reader saw `ES` where the page meant Spain.

They come from [flag-icons](https://github.com/lipis/flag-icons) 7.2.3 (MIT, © Panayiotis Lipiridis),
copied here so the site fetches nothing from anywhere else — the same rule every other asset follows.

`es.svg` is that file's first two paths, which are the three stripes, without the coat of arms: at this
size the arms are a smudge of ten colours, and the flag without them is a flag of Spain rather than an
approximation of one.

`at.svg` follows the same three-band geometry and `id` as that library's Austrian file; it was written
by hand for this repository rather than copied, and should be compared with flag-icons before release.

`nl.svg` is written the same way for the Netherlands: three horizontal bands, red, white and blue, in
the colours flag-icons uses. It too should be compared with flag-icons before release.

`ro.svg` uses three equal vertical bands: blue, yellow and red.

`gr.svg` (nine blue and white stripes with the white cross in the canton) and `pl.svg` (white over red)
were written by hand for this repository in the colours flag-icons uses; compare them with flag-icons
before a later release.
